# Retail Sales Analytics Dashboard | Power BI

## Dashboard Preview

![Retail Sales Analytics Dashboard](dashboard-preview.png)

## Project Overview

An interactive retail sales analytics dashboard developed using Microsoft Power BI to explore sales performance, customer segments, product rankings, and geographical sales distribution.

## Dashboard Features

- **Total Sales:** Approximately 10.67M
- **Total Returns:** Approximately 896.81K
- **Total Orders:** Approximately 26K
- **Total Customers:** Approximately 4K

*The KPI values represent the unfiltered dashboard view.*

## Visualizations

1. **Monthly Sales Performance** — Sales trends over time.
2. **Top 10 Countries by Sales** — Comparison of revenue across countries.
3. **Top 10 Best-Selling Products** — Identification of leading products.
4. **Sales by Customer Segment** — Comparison of known and unknown customer sales.

## Interactive Filters

- Year
- Country

Both filters dynamically update dashboard visuals and KPI cards.

## Tools and Skills

- Microsoft Power BI Desktop
- Data visualization and dashboard design
- DAX measures
- Interactive slicers
- Business performance analysis

## Project Files

- `Online_Retail_Analytics_Dashboard.pbix` — Editable Power BI report.
- `Retail_Sales_Dashboard.pdf` — Static dashboard preview.

## How to Use

1. Download the `.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard using the Year and Country filters.

## Project Purpose

This portfolio project demonstrates the ability to create interactive business intelligence reports and communicate retail sales performance through clear, structured visualizations.
